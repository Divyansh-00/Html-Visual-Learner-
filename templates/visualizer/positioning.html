    CSS Positioning Visualizer

    Select a positioning mode and adjust offsets to see exactly how elements are placed.

    Position Mode
    position: static
    Default. Element is in normal document flow. Offsets have no effect.
    position: relative
    Element stays in flow but shifts relative to its normal position.
    position: absolute
    Removed from flow. Positioned relative to nearest positioned ancestor.
    position: fixed
    Removed from flow. Fixed relative to the browser viewport.
    position: sticky
    Acts like relative until scroll threshold, then sticks like fixed.
    Offset Values
    top 0px
    left 0px
    right auto
    bottom auto

    static elements ignore offset properties.
